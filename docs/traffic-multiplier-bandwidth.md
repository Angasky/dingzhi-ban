# 节点模板、流量倍率与节点限速

本批功能已在本地源码实现，尚未推送仓库或部署到 vpn.mxvv.cn。

## 节点创建模板

入口为「节点管理 → 选择服务器创建节点」，也可从服务器的「节点 / 中转」进入。服务器须先接入总控。

| 模板 | Xray / 已适配 Xray 面板 | 独立 sing-box |
| --- | --- | --- |
| VLESS + Reality / Vision | 支持 | 支持 |
| VMess + TCP | 支持 | 支持 |
| Shadowsocks AES-128-GCM | 支持 | 支持 |
| Trojan + TLS | 支持，需远端证书 | 支持，需远端证书 |
| VLESS + WebSocket + TLS | 支持，需远端证书 | 支持，需远端证书 |
| Hysteria2 / TUIC | 不提供 | 支持，需远端证书 |

模板生成凭据并创建专属入站，自动绑定当前订阅；候选 SNI 可从服务器发起测试后选择。模板展示不意味着所有面板旧版本都支持对应接口，接入时仍需验证 API 与内核版本。已有节点可按[服务器节点工作流](server-node-workflow.md)导入；独立内核的原有非受管配置不会自动接管。

## 流量倍率

在当前订阅的「流量与有效期」设置「流量计费倍率」。默认 1 倍，可设置 0–100，最多三位小数。自动计量需启用服务器强制限制并绑定专属入站；关闭强制限制时仍为手动维护计费用量。

例如设置 2 倍，服务器新采集到实际使用 1 GiB，订阅已用额度增加 2 GiB，剩余额度相应减少。上传和下载均使用该订阅的倍率，多个绑定节点累计到同一订阅。0 倍只记录原始流量、不增加计费流量，订阅到期仍会撤销节点。

- 页面及各客户端订阅的用量、剩余额度、超额判定均使用计费值。
- 原始采集值另行展示，不含管理员手工填写的历史基数；用量输入框也是计费值。
- 历史账单不重新翻倍。修改倍率前先按旧倍率采样结算，失败则保留旧倍率，避免把离线期间的用量错误套用新倍率。
- 小数倍率按字节累计余数并保存，避免小流量分次采样丢失；内核计数重置按新计数继续累计。
- 自动采集和远端撤销存在轮询与网络延迟，并非每字节实时断开；服务器离线时记录失败并重试。到期、超额删除后，续期不会自动重建已删除节点。

## 对某个订阅的某个节点限速

先将专属入站绑定目标订阅，然后在「流量与有效期 → 专属入站 → 节点带宽限制」或服务器节点列表的「节点限速」设置：

- 客户端上传上限、客户端下载上限，单位 Mbps；8 Mbps 约为 1 MB/s。
- 每个方向可单独设置 0.1–10000 Mbps，最多三位小数，留空表示该方向不限。
- 点击「取消此节点限速」清除该入站规则。关闭订阅额度限制不会取消已应用的节点限速。

限制作用于该服务器的独占入站端口，支持 IPv4 / IPv6 及已适配协议的 TCP / UDP。使用同一专属节点的多台设备共享这个上限。多个节点分别限速，不是整个订阅共享一个带宽池。多用户共用入站及端口复用会被拒绝；SSH 和面板管理端口也不能用于此限速。节点身份变化时拒绝应用，防止误限其他节点。

服务器需预装 nftables、使用 systemd，并允许总控执行 root 命令；缺少依赖会报错，不会显示成功。限速通过内核 nftables 超速丢包实现，允许短时突发，**不是平滑队列整形**。TCP 可能重传，实际吞吐可能低于上限；UDP / QUIC 可能丢包或产生本地发送错误，生产使用前需按实际客户端协议验证。这里统计网络数据包大小，与代理内核的计费字节并非完全相同。

程序只维护 `inet mxioc_bandwidth` 表，不清空服务器其他防火墙规则或更改 qdisc。规则先校验再通过事务替换，并创建 `mxioc-bandwidth-restore.service` 在重启后恢复；应用或持久化失败会尝试回滚旧规则并报告失败。页面显示的是上次成功应用记录，不代表实时防火墙健康状态。其他工具清空规则、外部面板直接删除节点或手动更改端口后，需要在总控重新核对并应用 / 清理限速。

通过总控删除受限节点时先清除限速；删除失败会尝试恢复原限速。订阅超额或到期的撤销流程也联动清理，失败保留错误以便重试。有限速的节点需先取消限速才能修改端口、监听或协议；服务器有未清理限速时不能直接从总控移除或更换类型。

## 验证范围

已通过倍率、余数累计、零倍率、旧倍率结算、离线拒绝变更、专属绑定校验、限速失败回滚和删除清理等自动测试，三个主题的表单也通过本地 Chromium 检查。

另在隔离 Linux 用户 / 网络命名空间使用真实 nftables 测试 UDP，未更改宿主防火墙。以约 4 Mbps 发送，预热 1.5 秒后测量 3 秒：

| 场景 | 实测速率 |
| --- | --- |
| 上行设为 1 Mbps | 0.973 Mbps |
| 下行设为 2 Mbps | 1.944 Mbps |
| 未限制的另一个端口 | 4.000 Mbps |
| IPv6 设为 1 Mbps | 0.955 Mbps |
| 取消限制后 | 4.000 Mbps |

这些是本地内核限速测试；未在你的生产服务器、真实代理连接或各手机客户端上验证本批限速效果。
